# SE-Adaptive-Task-and-Deadline-Management

Repository for the **Adaptive Task & Deadline Management** project.

## Repository Layout

- `frontend/`: Next.js App Router frontend application with TypeScript, Tailwind CSS, and shadcn/ui.

## Frontend Setup

Navigate to the `frontend/` directory to get started:

```bash
cd frontend
npm install
cp .env.example .env.local
npm run dev
```

For detailed frontend documentation, see [frontend/README.md](frontend/README.md) and [frontend/docs/architecture.md](frontend/docs/architecture.md).
